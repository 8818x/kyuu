10 new visual identities for Food Diary

All ten use the same layout and the same example photographs, so only the visual system changes. Ranked by fit for a personal, photograph-first food diary — this is a shortlist, not a selection.

Visual exploration only. No production file, stack, or dependency was changed. Photographs are labelled examples, not real visits.

01

Silver Halide

A premium gallery at closing time. Near-black with a silver thread, quiet and expensive. The photograph is the only bright thing in the room.
